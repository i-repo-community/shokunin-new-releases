# User Management

Approve and manage craftsman (LINE user) registrations.

## User list

Registered users are listed with:

- Name, email address, phone number, company name
- Status (pending / approved / rejected)
- Registration date

You can **search** by name, email, phone, or company, and **filter** by status.

## Changing a user's status

| Action | What it does |
|---|---|
| Approve | Approves the user and grants access to the service |
| Reject | Rejects the registration |
| Hold | Returns an approved user to pending |

When a status changes, the user is **automatically notified via a LINE message**.

## Deleting a user

Users can be deleted after a confirmation dialog. The user is notified via LINE on deletion as well.
