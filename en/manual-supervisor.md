# Supervisors (admin screen)

Features for site supervisors are available in the browser-based **admin screen**.

## Logging in

- The admin screen uses **LINE Login**.
- Click "Log in with LINE" to go to the LINE authentication screen.
- On a PC, a QR code is shown — scan it with the LINE app on your smartphone to log in.
- Log out from the dashboard menu.

The pages in this section explain each screen.
