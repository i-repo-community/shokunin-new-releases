# Report List, History & Map

## Report List

Open "Report List" from the rich menu any time to see the reports you've created. The list appears in the chat as swipeable cards (a carousel).

Each card shows:

| Item | Contents |
|---|---|
| Project name | The name you entered |
| Preview | Report thumbnail (tap to view the PDF) |
| Project number | Shows "no project number" if not set |
| Last updated | When the report was last changed |
| Actions | Edit project info · AI Comment · Add photos · Download · Rebuild · Delete |

### Card colors

The card background shows the report's state at a glance:

- **Green** — has a project name and at least one photo (nearly complete)
- **Gray** — missing photos or missing a project name

## History & Map

- **History** — look back through previously created reports.
- **Map** — find reports with location data on a map; handy when you remember the site but not the report.
