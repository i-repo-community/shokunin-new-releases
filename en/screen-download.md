# Download

Finished reports can be downloaded as PDFs. Choose "Download" on a report in the Report List to open the download screen.

## What the download screen offers

| Feature | What it does |
|---|---|
| Thumbnail & info | Review the report's contents |
| Download | Download the report PDF (file name is "project name + report date") |
| QR code | The screen's URL as a QR code — tap to enlarge or save |
| Open in browser | Open this screen in the device's browser |
| Email | Opens your mail app with the download URL pasted in |
| Share | Opens LINE's forward menu |

## Good to know

- Share the download URL to hand the report to people who don't use LINE (the office, the ordering party, and so on).
- The URL contains an encrypted ID, so it can't be guessed by third parties.
- Downloads have an expiry and a usage limit; if a link expires, open the download screen again from the Report List.
