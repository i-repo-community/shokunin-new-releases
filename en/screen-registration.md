# Registration & Profile

## How registration works

1. **Add the account** — Add the Shokunin.new LINE official account (Azusa) as a friend.
2. **Fill in the registration form** — After adding, Azusa sends you a link to the user registration form. Enter:
   - First name (required)
   - Last name (required)
   - Email address
   - Phone number
   - Company name
3. **Wait for approval** — After submitting, your account is in a "pending approval" state.
4. **Approved** — Once an administrator approves you, all features become available.

## While waiting for approval

- If you send a message while pending, Azusa asks you to wait for administrator approval.
- If you haven't registered yet and send a message, Azusa replies with a link to the registration form.

## Rich menu

The rich menu at the bottom of the chat gives you one-tap access to the main features.

| Menu item | What it does |
|---|---|
| How to use | Opens the user guide |
| Tutorial video | Opens a walkthrough video |
| Project info form | Opens the construction information form |
| Select photos | Opens the photo picker |
| Report List | Opens your list of reports |
| Azusa Advice | Pick a report to get advice on |

Note: the rich menu is displayed in Japanese only, but your messages are recognized in both Japanese and English.
