# Interview Mode

In interview mode, **Azusa asks the questions** and the report writes itself from your answers. No need to compose text or hunt for fields.

## How it works

1. Start an interview; Azusa asks about what the report needs, one question at a time.
2. Answer in the chat — your answers flow into the report as you go.
3. When the questions are done, a confirmation card shows the content before submitting.
4. Confirm and submit, and the report is complete.

## Handy features

- **Pause & resume** — you can pause an interview and pick it up again later.
- **Draft preview** — check a draft of the report PDF before submitting.
- **Location** — the site's location can be included in the report.
