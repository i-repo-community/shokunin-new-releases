# Dispatch Management

Create construction plans and assign them to craftsmen. Assigned craftsmen receive an automatic LINE notification that work has been dispatched to them.

## Report types

The screen has tabs for two kinds of reports:

- **Construction photo reports** — dispatch for regular photo reports
- **Workflow reports** — dispatch for reports that follow a [workflow definition](admin-workflow-definitions.html)

## How dispatching works

1. Enter the project information (name, location, date, and so on) and create a dispatch.
2. Assign the craftsmen in charge.
3. A notification arrives in each craftsman's LINE — from there they can jump straight to editing project info, checking photo comments, or viewing the map.
4. Track each dispatch's progress (report submission status) in the list.
