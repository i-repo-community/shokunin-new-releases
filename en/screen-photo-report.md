# Photo Reports

A photo report consists of **project information** (project number, report date, project name, company, ordering party, reporting party, general comment) and **photo information** (photos and photo comments). Finished reports can be downloaded and shared as PDFs.

## Creating a report

There are two ways.

### Method 1: Start from Azusa advice

1. Send Azusa your project information, either way:
   - **Free-form message** — describe the work in your own words; the AI reads out the project name and other details.
   - **Project info form** — open it from the rich menu and enter the project name (required), project number, ordering party, reporting party, and company.
2. Azusa replies with advice for working safely.
3. Azusa then asks "Do you want to create a report with this project information?" — choose **Yes** and the report is created.
   - At this point it contains the project information only; photos come later.
   - The Report List appears automatically after creation.

### Method 2: Start by sending photos

1. Send site photos from the chat, or via "Select photos" in the rich menu.
2. Azusa asks whether to **update** an existing report or **create a new one** — choose "create new".
3. A report containing your photos is created. Project information can be added later.

## Updating a report

### Adding photos

Send photos and choose **update**; the Report List appears. Pick the report to update and the photos are **added** to it.

### Editing from the Report List

Open "Report List" from the rich menu. Each report offers these actions:

| Action | What it does |
|---|---|
| Edit project info | Opens the project info form; entries overwrite the report's basic information |
| AI Comment | Opens the photo-comment editor: reorder photos, auto-generate photo comments with AI, and auto-generate a work summary from the comments |
| Add photos | Opens the photo upload screen; upload several photos at once |
| Download | Opens the download screen |
| Rebuild | Creates a new report carrying over only the basic information |
| Delete | Deletes the report (including its photos — cannot be undone) |

Note: replacing or deleting individual photos in an existing report is not supported; photo comments and project information can only be overwritten.
