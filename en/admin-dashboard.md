# Dashboard

The screen shown after login — your tenant's status at a glance.

## Overview (statistics)

- **Total users** — number of registered craftsmen
- **Pending / Approved / Rejected** — breakdown of user approval status

## Recent reports

Recently submitted reports are listed here. "Open report history" shows all of them.

## Quick actions

Shortcuts to the screens you use most:

| Action | What it does |
|---|---|
| User Management | View and manage tenant users |
| Dispatch | Create dispatches and check progress |
| Tenant Settings | Configure tenant settings |
| QR Poster | Generate a printed QR poster for on-site report submission |
