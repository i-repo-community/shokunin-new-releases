# ダウンロード

完成した報告書は PDF としてダウンロードできます。報告書リストの「ダウンロード」を選ぶと、ダウンロード画面が開きます。

## ダウンロード画面でできること

| 機能 | 内容 |
|---|---|
| サムネイル・基本情報 | 報告書の内容を確認する |
| ダウンロード | 報告書 PDF をダウンロードする（ファイル名は「工事名 + 報告日」） |
| QR コード | この画面の URL を QR コードで表示。タップで拡大・保存できる |
| ブラウザで開く | 端末のブラウザでこの画面を開く |
| メール | ダウンロード画面の URL が貼り付けられた状態でメーラーを起動する |
| 共有 | LINE の転送メニューを開いて共有する |

## 署名

ダウンロード画面では、報告書に署名できます（画面のタイトルは「報告書に署名」）。

1. 枠の中に指で署名します。署名するまで「署名して完了」ボタンは押せません。
2. 「署名して完了」を押すと、署名が保存され、報告書が完了になります。書き直したいときは、押す前に「クリア」を押してください。
3. 署名すると「この報告書は署名済みです」と署名の画像が表示されます。書き直す場合は「再署名」を押します。

- 署名を描いたまま「PDFをダウンロード」・メール・共有を押した場合も、署名は自動で保存されます。
- 署名には位置情報が記録されます。初めて署名するときに位置情報の利用を確認された場合は、許可してください。
- 会社の設定によっては、署名後に「管理者の承認待ち」と表示され、管理者の承認をもって完了になります。
- 署名の保存中は、保存が終わるまで「PDFをダウンロード」・メール・共有は押せません（写真報告書では「PDFを更新中…」と表示されます）。保存後は署名入りの最新の PDF が開きます。
- 「署名は保存されました。PDF はまだ更新中です。」と表示された場合、署名は保存されていますが、PDF にはまだ反映されていません。しばらくしてからもう一度お試しください。

### PDF への署名の印刷

署名は、写真報告書（工事写真報告書）PDF の **2 ページ目「作業コメント」欄**に印刷されます。

- 「管理者の承認待ち」の間も印刷されます。
- 「再署名」すると、PDF も新しい署名に変わります。
- 管理者が署名を却下・削除すると、PDF から署名は消えます。
- 2 ページ目の「作業コメント」欄には署名が入ります。作業コメントは 1 ページ目など、ほかのページに引き続き表示されます。
- この機能が使えるようになる前に署名した報告書は、次に報告書を更新したときに署名が印刷されます。
- 業務報告書（業務フロー）の PDF には印刷されません。

## 知っておくと便利

- ダウンロード画面の URL を共有すれば、LINE を使っていない相手（事務所や発注者など）にも報告書を渡せます。
- URL には暗号化された ID が使われており、第三者が推測して開くことはできません。
- ダウンロードには有効期限と回数の上限があります。期限が切れた場合は、報告書リストから再度ダウンロード画面を開いてください。
