# 更新情報

職人.new の新機能・改善・修正をお知らせします。

## 2026-10

### 新機能

- **現場掲示物をまとめて作成できるようになりました**: 管理画面の「現場掲示物」から、建設業の許可票、労災保険関係成立票、建築基準法による確認済、緊急連絡表、写真報告用QRを現場ごとに作成できます。PDFプレビューで確認してから、PDFまたはExcelで出力できます（[現場掲示物](admin-site-notices.html)）。
- **業務フローを掲示物にできるようになりました**: 過去の業務フロー報告から工程を取り込み、工程名・内容・注意点・担当を編集して掲示できます。長いフローは掲示向けに8工程以内へ整理できます（[現場掲示物](admin-site-notices.html)）。
- **作成した掲示物PDFを報告詳細から確認できるようになりました**: 現場に紐づけて保存した最新のPDFを、管理者が「報告履歴」の写真報告の「詳細」タブから表示・ダウンロードできます。新しく完成版PDFを作成すると、前のPDFは置き換えられます。

- **署名が写真報告書の PDF に印刷されるようになりました**: ダウンロード画面で「署名して完了」を押すと、署名が写真報告書 PDF の 2 ページ目「作業コメント」欄に印刷されます。管理者の承認待ちの間も印刷され、再署名すると新しい署名に変わり、管理者が却下・削除すると消えます。これより前に署名した報告書は、次に報告書を更新したときに印刷されます（[ダウンロード](screen-download.html)）。

- **リッチメニューがタブで切り替えられるようになりました**: 「写真報告」「業務報告」「使い方」の 3 つのタブで、ボタンが用途ごとに分かれます。報告書の一覧も「写真報告書リスト」と「業務報告書リスト」に分かれ、「工事情報フォーム」は「報告書作成」になりました。LINE の言語設定が日本語以外の方には英語のメニューが表示されます（[登録・プロフィール](screen-registration.html)）。

### 改善

- **署名の保存中は「PDFを更新中…」と表示されるようになりました**: 保存が終わるまで「PDFをダウンロード」・メール・共有は押せません。保存後は署名入りの最新の PDF が開きます（[ダウンロード](screen-download.html)）。
- **リッチメニューのボタンの並びを変更しました**: 写真報告タブの下段で、「あずさアドバイス」と「写真報告書リスト」の位置を入れ替えました。下段は左から「あずさアドバイス」「写真報告書リスト」「工事履歴」の順です（[登録・プロフィール](screen-registration.html)）。
- **リッチメニューに「作業予定」ボタンを追加しました**: 写真報告タブの上段が「報告書作成」「写真選択」「作業予定」の 3 つになりました。「作業予定」から「今日」「明日」「今週（7日間）」を選ぶと、工事開始予定日がその期間にある写真報告書を確認できます（[登録・プロフィール](screen-registration.html)）。

## 2026-09

### 新機能

- **業務開始がカード表示になりました**: トークで「業務開始」を送ると、業務フローが帳票のサムネイル付きのカードで表示されます。「この帳票で開始」をタップすると、そのままフォームが開きます（[業務フロー](screen-workflow.html)）。サムネイルは管理画面の[業務フロー定義](admin-workflow-definitions.html)でも確認・更新できます。
- **フォームの表示を切り替えられるようになりました**: 流れが設定された業務フローでは、「1項目ずつ」と「シートごと」の表示を切り替えられます。入力した内容はどちらの表示にも引き継がれます。シートごとの表示では、分岐の質問（はい／いいえ）にもその場で回答でき、回答により入力不要な項目はグレーで表示されます。
- 管理画面のサイドバー「システム設定」に **OpenAPI** を追加しました。外部システム連携でお使いいただく API の仕様を、管理画面から直接ご確認いただけます。管理者アカウントでログインしている場合のみ表示され、別のタブで開きます。

### 改善

- 業務フローのフォームで、あずさのアイコンの下に「アイコンをタップするとあずさに相談できます」と表示されるようになりました。また、アイコンをタップした項目について、あずさがまず答えるようになりました（チャットに「（項目名） について」と表示されます）。
- 業務フローのフォームの**マスター選択**で、入力欄をタップすると一覧が表示されるようになりました。キーワードがわからなくても一覧から選べます。入力欄の下には検索する項目（一覧を読み込むと入力例も）が表示され、一致するデータがない場合は「一覧を表示」で一覧に戻れます。
- 外部システム連携用のアクセスキーの一覧で、**期限切れ・失効したキーを隠す**ようにしました。現在お使いいただけるキーだけが表示され、チェックボックスで隠れているキーも確認できます。キーそのものは削除されません（過去の報告書の作成者の記録を残すためです）。

### 修正

- 複数の報告書がほぼ同時に作成されたときに、PDF の作成に失敗することがある問題を修正しました。
- i-Reporter からの応答が止まったときに、画面が待ち続けたままになることがある問題を修正しました。一定時間で終了してエラーをお知らせします。
- 報告書の編集内容が失われることがある問題を修正しました。報告書のPDFを作り直している間に、別の方が同じ報告書のコメントや内容を編集すると、その編集が保存されないことがありました。
- PDFの作成に失敗したときに、それまで見られていたPDFまで表示できなくなる問題を修正しました。新しいPDFの作成に失敗しても、以前のPDFはそのまま残ります。
- 報告書に印字される更新日が、報告書の内容を最後に変更した日付になるようにしました。これまでは、内容を変えずにPDFを作り直しただけでも、その日付が新しくなることがありました。

## 2026-08

### 新機能

- 業務フローのフォームで、新しい入力項目に対応しました。
  - **トグル選択**: 丸いボタンから 1 つを選ぶ選択項目に入力できるようになりました。
  - **トグル集計**: トグル選択の合計点を自動で表示します。
  - **時刻計算**: 時刻の項目どうしの差（所要時間など）を自動で計算します。
- **自由描画（手書き）**: ペンで自由に手書きできる新しい項目を追加しました。書く・消す・元に戻す・全部消す、の操作ができます。保存した報告書を開き直して、描いた内容の続きを編集することもできます。
- **i-Reporter から帳票定義を取り込む・同期する**（自社の i-Reporter をお持ちのお客様向け。i-Reporter のアカウントをお持ちでないお客様には表示されません）: [業務フロー定義](admin-workflow-definitions.html)の画面から、i-Reporter にある帳票定義を一覧表示してそのまま取り込めるようになりました。また、登録済みの定義が i-Reporter 側で更新された場合は「更新あり」と表示され、ワンタップで最新版を取得できます。XML ファイルを書き出して手作業でアップロードする必要がなくなります（手動アップロードもこれまでどおりご利用いただけます）。なお、これまでに手動でアップロードした業務フローは、一度「定義を同期」を実行してから「更新あり」の対象になります。

### 改善

- 「次へ」をタップしたとき、未入力の必須項目まで自動でスクロールする対象を、すべての項目（トグル選択・複数選択などを含む）に広げました。
- 操作ログで、外部連携用のアクセスキーに関する操作を種類ごとに絞り込めるようにしました（「API認証情報の発行」「API認証情報のローテーション」「API認証情報の失効」）。外部システムとの連携をご利用のお客様のみ、ログに表示されます。

### 修正

- 「あずさアドバイス」と、写真を既存の報告書に追加するときのリストに、選べない報告書が並んでしまう問題を修正しました。どちらのリストにも写真報告書のみが表示されます。業務フローの報告書に写真を追加する場合は、「報告書リスト」の「写真追加」ボタンをご利用ください。
- 金額の項目で、円マーク「¥」が正しく表示されるようにしました。
- 「5,700円」のようにカンマを含む選択肢が、正しく表示されるようにしました。
- 選択肢をタップしたとき、タップした選択肢だけが選択状態になるようにしました（似た選択肢が一緒に選択されてしまう場合を修正）。
- 任意の単一選択項目で、選択中の選択肢をもう一度タップすると選択を解除できるようにしました（必須項目では選択は解除されません）。
- LINE アプリ側の仕様変更（2026年10月）のあとも、報告書作成フォームがこれまでどおり開くようにしました。
- 工事名や会社名などがあらかじめ入力された状態でフォームを開いたとき、「?」や「+」を含む文字が欠けずに表示されるようにしました。
- リンクの文字が一部壊れている場合でも、LINE から開く各画面がエラーにならずに表示されるようにしました。
