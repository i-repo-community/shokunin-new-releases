# ダッシュボード

ログイン後に表示される、テナント全体の状況をひと目で把握できる画面です。

## 概要（統計）

- **総ユーザー数** — 登録済みの職人の数
- **承認待ち / 承認済み / 却下** — ユーザーの承認状況の内訳

## 直近の報告

最近提出された報告書が一覧表示されます。「報告履歴を開く」からすべての報告を確認できます。

## クイックアクション

よく使う画面へのショートカットです。

| アクション | 内容 |
|---|---|
| ユーザー管理 | テナントユーザーの表示・管理 |
| 工事手配 | 工事手配の作成と進捗確認 |
| テナント設定 | テナント設定の構成 |
| QR ポスター | 現場報告提出用の印刷 QR ポスターを生成 |
