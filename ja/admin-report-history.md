# 報告履歴

職人が提出した報告書の履歴を確認する画面です。

## できること

- 提出された報告書を一覧で確認できます。
- 各報告書の**詳細**と **PDF** をタブで切り替えて確認できます。PDF は新しいタブで開くこともできます。
- 業務フローの報告は、帳票名称・リビジョン・提出者とあわせて一覧表示されます。

現場に行かなくても、事務所から報告内容をリアルタイムに確認できます。
