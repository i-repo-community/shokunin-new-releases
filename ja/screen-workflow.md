# 業務フロー

業務フローは、**決められた手順に沿って報告する**ための機能です。現場監督が定義した項目（フォーム）に沿って入力していくため、報告の抜け漏れを防げます。

## 使い方

1. リッチメニュー（業務報告タブ）の「業務開始」をタップするか、トークで「業務開始」を送ると、使える業務フローが**カード**で届きます。各カードには帳票の 1 ページ目のサムネイルが表示されるので、見た目で選べます（最近更新された業務フローから順に表示されます）。
2. 使いたいカードの「**この帳票で開始**」をタップすると、「フォームを準備しています…」と表示されたあと、そのままフォームが開きます。
3. 画面の案内に沿って、手順ごとに写真や情報を入力します。
4. すべての手順を終えて送信すると、報告書が作成されます。

- 工事手配で割り当てられた業務フローは、これまでどおり手配の通知に届く「業務開始」のカードから開始します。
- フォームを開けなかった場合は、「もう一度試す」をタップしてください。

## 表示の切り替え（1項目ずつ／シートごと）

すべての業務フローで、フォーム上部のボタンで表示を切り替えられます。流れ（手順）が設定されていない業務フローでは、帳票の項目順に 1 項目ずつ進みます。

- **1項目ずつ**: 1 画面に 1 項目ずつ、案内や分岐（はい／いいえ）に沿って進みます。
- **シートごと**: 帳票のシートごとに、項目をまとめて表示します。全体を見渡しながら入力したいときに便利です。

どちらの表示で入力した内容も、もう一方にそのまま引き継がれます。最後に選んだ表示は、次に開いたときも使われます（まだ選んでいない場合、流れが設定された業務フローは「1項目ずつ」、それ以外は「シートごと」で開きます）。

シートごとの表示では、次のようになります。

- 分岐の質問（はい／いいえ）は、手順の順番どおりの位置（その前の項目のすぐ下）に表示され、その場で回答できます。回答すると、関係する項目がすぐに表示されます。回答済みの質問も、はい／いいえをタップすれば変更できます。
- 分岐の回答により入力しなくてよい項目は、「**回答内容により入力不要です**」とグレーで表示されます（入力は不要で、送信もされません）。
- まだ回答していない分岐の先にある項目は、「「（質問）」に回答すると表示されます」と表示されます。その質問に回答すると表示されます。
- すべての質問に回答すると、シートごとの表示のまま送信できます。回答（または入力内容）によってフローが終了する場合は、その旨が表示され、その回答や項目を変更するまで送信できません。

## ステップ一覧（ジャンプ移動）

フォーム上部の「ステップ一覧」ボタンから、すべてのステップを一覧できます。

- ステップ名で検索し、タップするとそのステップへ直接移動できます（以降は通常どおり「戻る／次へ」で操作できます）。
- 分岐で選択していない側のステップはグレー表示され、その分岐を選択すると利用できるようになります。
- 確認画面でも、項目をタップするとそのステップへ直接移動できます。

## あずさに相談する

フォームの項目の横に AI アシスタント「あずさ」のアイコンが表示されている場合は、アイコンをタップするとあずさに相談できます（アイコンの下に「アイコンをタップするとあずさに相談できます」と表示されます）。

- タップした項目について相談できます。チャットの上部に「（項目名） について」と表示され、あずさはまずその項目について答えます。フォーム全体の内容も確認したうえでアドバイスします。
- あずさはアドバイスのみを行い、項目に値を入力することはありません。入力はご自身で行ってください。
- 別の項目のアイコンから開き直すと、チャットに区切りが入り、その項目についての相談に切り替わります。
- あずさのアイコンは「1項目ずつ」表示で表示されます。

## 項目どうしのつながり（ネットワーク）

i-Reporter の帳票で項目どうしがネットワークでつながっている場合、フォームでも同じように動きます。

| つながり | フォームでの動き |
|---|---|
| 入力不可 | 前の項目を入力するまで入力できません。🔒「「〇〇」を入力すると入力できます」と表示されます。前の項目を消すと、つながっている項目の入力も消えます。 |
| 警告のみ | 前の項目が未入力のまま入力しようとすると「前の入力項目が入力されていません。本当に入力しますか？」と確認されます。 |
| 選択肢の絞り込み | 前の項目で選んだ内容に合う選択肢だけが表示されます。合う選択肢がないときは「「〇〇」で選んだ内容に対応する選択肢はありません」と表示されます。 |
| 必須になる | 前の項目で特定の内容を選ぶと、その項目が必須（＊）になります。 |
| 大小関係 | 前の項目より大きい・以上などの決まりがある項目で、決まりに合わない値を入れると「（比較エラー）」と表示され、提出できません。 |

- 前の項目を入力して制限が解除されると、🔗 「〇〇」と連動中 と表示され、項目がつながっていることがわかります。選択肢が絞り込まれているときは「絞り込み中」、必須になっているときは「必須」も表示されます。
- ステップ一覧でも、制限中の項目には 🔒（警告のみは ⚠）、連動中の項目には 🔗 が表示されます。
- シートごとの表示では、項目を入力すると、つながっている次の項目へ自動で移動します。

## 入力できる項目

写真や文字のほかにも、さまざまな種類の項目を入力できます（どの項目が表示されるかは現場監督の定義によります）。

- **トグル選択**: 丸いボタンから 1 つを選びます。任意の項目では、選択中の選択肢をもう一度タップすると選択を解除できます。
- **トグル集計**: トグル選択の合計点が自動で表示されます。
- **時刻計算**: 入力した時刻から、差（所要時間など）が自動で計算されます。
- **自由描画（手書き）**: ペンで自由に手書きできます。書く・消す・元に戻す・全部消す、の操作ができます。保存した報告書を開き直して、続きを編集することもできます。
- **マスター選択**: 登録済みのデータ（マスター）から選びます。入力欄をタップすると一覧が表示されるので、そこから選べます。一部を入力すると絞り込めます（入力欄の下に、どの項目で検索するかが表示され、一覧を読み込むと入力例も表示されます）。一致するデータがない場合は「一覧を表示」で一覧に戻れます。「一覧を閉じる」で一覧を閉じられます。

## ポイント

- 入力する項目や手順は、現場監督が管理画面（[業務フロー定義](manual.html)）で定義したものです。現場ごと・業務ごとに内容が変わります。
- 作成された報告書は、リッチメニューの「業務報告書リスト」（[報告書リスト](screen-report-list.html)）に表示され、通常の写真報告書と同じように編集・ダウンロードができます。
