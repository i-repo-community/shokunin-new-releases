# 写真報告書

写真報告書は、**基本情報**（工事番号・報告日・工事名・会社名・注文者・報告者・全体コメント）と**写真情報**（写真・写真コメント）で構成されます。完成した報告書は PDF としてダウンロード・共有できます。

## 報告書を作成する

作成方法は 2 つあります。

### 方法 1: あずさアドバイスから作成

1. あずさに工事情報を送ります。送り方は 2 つ。
   - **フリーメッセージ** — 工事の内容をそのまま文章で送ると、AI が工事名などの情報を読み取ります。
   - **工事情報フォーム** — リッチメニューの「工事情報フォーム」から、工事名（必須）・工事番号・発注者・報告者・会社名を入力します。
2. あずさが安全に作業するためのアドバイスを返信します。
3. 続けて「この工事情報で報告書を作成しますか？」と聞かれるので、「はい」を選ぶと報告書が作成されます。
   - この時点では写真はまだ無く、工事情報だけが入った状態です。
   - 作成後、報告書リストが自動で表示されます。

### 方法 2: 写真を送って作成

1. トーク画面またはリッチメニューの「写真選択」から、現場写真を送ります。
2. あずさが「報告書を更新しますか？新規作成しますか？」と聞くので、「新規作成」を選びます。
3. 送った写真が入った報告書が作成されます。工事情報は後から追加できます。

## 報告書を更新する

### 写真を追加する

写真を送り、「更新」を選ぶと報告書リストが表示されます。更新したい報告書を選ぶと、送った写真がその報告書に**追加**されます。

### 報告書リストから編集する

リッチメニューの「報告書リスト」から、各報告書に対して次の操作ができます。

| アクション | 内容 |
|---|---|
| 工事情報編集 | 工事情報フォームを開き、基本情報を入力・上書きする |
| AI コメント | 写真コメントの編集画面を開く。並べ替え、AI による写真コメントの自動生成、写真コメントからの作業報告の自動生成ができる |
| 写真追加 | 写真アップロード画面を開き、複数枚をまとめて追加する |
| ダウンロード | ダウンロード画面を開く |
| 作り直す | 基本情報だけを引き継いだ新しい報告書を作成する |
| 削除 | 報告書を削除する（写真データも削除。元に戻せません） |

※ 既存の写真の差し替え・削除には対応していません。写真コメントや工事情報は上書きのみ可能です。
