# インタビューモード

あずさが**インタビュー形式で質問**し、答えていくだけで報告書が仕上がる機能です。文章を考えたり項目を探したりする必要はありません。

## 使い方

1. インタビューを開始すると、あずさが報告書に必要なことをひとつずつ質問します。
2. 質問にトークで答えていくと、回答が報告書に反映されていきます。
3. すべての質問が終わると、送信前に内容の確認カードが表示されます。
4. 確認して送信すると、報告書が完成します。

## 便利な機能

- **中断・再開** — インタビューは途中で中断しても、後から続きを再開できます。
- **下書きプレビュー** — 送信前に、報告書 PDF の下書きを確認できます。
- **位置情報** — 現場の位置情報を報告書に含めることができます。
