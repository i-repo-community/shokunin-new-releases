# 工事手配

工事の予定を作成し、職人に割り当てる画面です。手配された職人には LINE で「工事が手配されました」と自動通知が届きます。

## レポートの種類

画面はタブで 2 種類のレポートに対応しています。

- **工事写真レポート** — 通常の写真報告書の手配
- **業務フローレポート** — [業務フロー定義](admin-workflow-definitions.html)に沿った報告の手配

## 手配の流れ

1. 工事情報（工事名・場所・日時など）を入力して手配を作成します。
2. 担当する職人を割り当てます。
3. 職人の LINE に通知が届きます。通知からは「工事情報を編集」「写真コメントを確認」「地図で確認」などの操作に直接進めます。
4. 手配ごとの進捗（報告の提出状況）を一覧で確認できます。
