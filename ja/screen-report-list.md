# 報告書リスト・履歴・マップ

## 報告書リスト

作成した報告書は、リッチメニューの「報告書リスト」からいつでも一覧できます。リストは LINE のトーク上にカード形式（カルーセル）で表示されます。

各カードには以下が表示されます。

| 項目 | 内容 |
|---|---|
| 工事名 | 入力した工事名 |
| プレビュー | 報告書のサムネイル（タップで PDF 表示） |
| 工事番号 | 未入力の場合は「工事番号なし」 |
| 更新日時 | 報告書の最終更新日時 |
| アクション | 工事情報編集・AI コメント・写真追加・ダウンロード・作り直す・削除 |

### カードの色

カードの背景色で報告書の状態がわかります。

- **緑** — 工事名があり、写真が 1 枚以上ある（完成に近い状態）
- **グレー** — 写真がない、または工事名がない

## 履歴・マップ

- **履歴** — 過去に作成した報告書をさかのぼって確認できます。
- **マップ** — 位置情報付きの報告書を地図上から探せます。現場の場所から報告書を見つけたいときに便利です。
