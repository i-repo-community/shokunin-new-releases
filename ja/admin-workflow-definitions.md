# 業務フロー定義

職人が現場で従う報告の手順（[業務フロー](screen-workflow.html)）を、フォームとして定義する画面です。

## できること

- 報告に必要な項目（テキスト・写真・選択肢など）を手順として定義します。
- 手順の流れを画面上で組み立てて、分岐や案内（ガイダンス）を設定できます。
- 定義した業務フローは[工事手配](admin-dispatch.html)で職人に割り当てます。
- 職人が提出した報告は[報告履歴](admin-report-history.html)で確認できます。

## i-Reporter から取り込む・最新に保つ

自社の i-Reporter をお持ちのお客様は、Designer から
XML を書き出して手作業でアップロードしなくても、画面上部の 2 つのボタンで定義を
管理できます。

### 対象となるお客様

ご利用の形態によって、この 2 つのボタンが表示されるかどうかが変わります。

| ご利用の形態 | 2 つのボタン | 帳票定義の登録方法 |
|---|---|---|
| **自社の i-Reporter をお持ちのお客様**<br>（i-Reporter をご契約いただき、自社の環境で運用） | 表示されます | 一覧から取り込む／XML アップロードのどちらでも |
| **i-Reporter のアカウントをお持ちでないお客様**<br>（職人.new が用意した共通の i-Reporter 環境をご利用） | 表示されません | XML ファイルのアップロード（これまでどおり） |

共通の i-Reporter 環境は複数のお客様が同時にご利用になるため、お客様ごとの帳票定義を
確実に分けてお預かりする目的で、アップロードの手順を維持しています。どちらの形態でも、
XML アップロードでの登録はこれまでどおりご利用いただけます。

### 「i-Reporter から取り込む」— まだ SNEW にない帳票を登録する

i-Reporter にある公開中の帳票定義を一覧表示します。取り込みたいものを選んで実行すると、
それぞれが業務フローとして新しく登録されます。

- すでに SNEW にある定義は「SNEW に登録済み」としてまとめて表示され、**選択できません**。
  取り込みで既存の業務フローが変更されることはありません。
- 一覧に出るのは**公開中**の帳票定義です。i-Reporter 側で「テスト」状態のものは表示されません。

### 「定義を同期」— すでにある帳票を最新にする

SNEW に登録済みの定義が i-Reporter 側で更新されていないかを確認し、更新があれば
最新版を取得します。新しい業務フローが作られることはありません。

- 更新がある業務フローには「**更新あり**」と表示され、ボタンにその件数が付きます。
- 同期していない間は、職人には更新前の手順が表示されたままになります。
- **XML を手動でアップロードした業務フローは、一度「定義を同期」を実行するまで
  「更新あり」が表示されません。** 同期のときに「どの時点の定義を取得したか」を記録し、
  その記録と i-Reporter 側を照らし合わせて判断するためで、記録が無い状態では
  新しいかどうかを判断できません。アップロード後に一度同期しておくことをおすすめします。
  「i-Reporter から取り込む」で登録した業務フローは取り込み時に記録されるため、
  最初から「更新あり」の対象になります。

## ポイント

- 現場ごと・業務ごとに異なる報告手順を、コードを書かずに定義できます。
- 定義を更新すると、以降の報告は新しい手順（リビジョン）で行われます。作成済みの報告は、
  開始したときの手順のまま変わりません。
- 上記 2 つのボタンは、**自社の i-Reporter をお持ちのお客様にのみ**表示されます（「対象となるお客様」をご覧ください）。
- XML ファイルを手動でアップロードする方法は、これまでどおりご利用いただけます。
