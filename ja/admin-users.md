# ユーザー管理

職人（LINE ユーザー）の登録を承認・管理する画面です。

## ユーザー一覧

登録ユーザーが以下の項目で一覧表示されます。

- 氏名、メールアドレス、電話番号、会社名
- ステータス（承認待ち / 承認済み / 却下）
- 登録日時

名前・メール・電話番号・会社名での**検索**と、ステータスでの**フィルタ**ができます。

## ステータスの変更

| 操作 | 内容 |
|---|---|
| 承認 | ユーザーを承認し、サービスの利用を許可する |
| 却下 | ユーザーの登録を却下する |
| 保留 | 承認済みユーザーを承認待ちに戻す |

ステータスを変更すると、対象ユーザーに **LINE メッセージで自動通知**されます。

## ユーザーの削除

確認ダイアログの後、ユーザーを削除できます。削除時も対象ユーザーに LINE で通知されます。
