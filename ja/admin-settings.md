# 設定

テナント（ご契約単位）の設定を構成する画面です。

- 報告書の生成に関する設定
- AI 機能に関する設定
- その他のテナント設定

設定項目の詳細は、ご契約時にご案内します。

## API 認証情報の一覧

外部システム連携用のアクセスキーの一覧では、**現在お使いいただけるキーのみ**が表示されます。

- 期限切れ・失効したキーは一覧から隠れます。件数つきのチェックボックスで表示を切り替えられます。
- 隠れているだけで、記録は残ります。**キーそのものは削除されません。**
  過去にそのキーで作成された報告書の「作成者」の記録を残すためです。

## OpenAPI（API 仕様）

外部システムとの連携をご利用のお客様向けに、サイドバーの「システム設定」から **OpenAPI** を開けます。
職人.new が提供する API の仕様を、そのままブラウザで確認できます。

- 管理者アカウントでログインしているときのみ表示されます。
- 別のタブで開くので、管理画面の表示はそのまま残ります。

ご利用の環境によっては表示されない場合があります。
