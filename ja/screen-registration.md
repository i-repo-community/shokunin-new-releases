# 登録・プロフィール

## 利用登録の流れ

1. **友だち追加** — 職人.new の LINE 公式アカウント（あずさ）を友だち追加します。
2. **登録フォームの入力** — 友だち追加すると、あずさからユーザー登録フォームへのリンクが届きます。フォームで以下を入力します。
   - 姓（必須）
   - 名（必須）
   - メールアドレス
   - 電話番号
   - 会社名
3. **管理者の承認を待つ** — 登録情報を送信すると「承認待ち」の状態になります。
4. **承認完了** — 管理者が承認すると、サービスのすべての機能が利用できるようになります。

## 承認待ちのあいだは

- 承認待ちの状態でメッセージを送ると、あずさが「管理者の承認をお待ちください」と案内します。
- 登録がまだの方がメッセージを送ると、あずさが登録フォームへのリンクを案内します。

## リッチメニュー

トーク画面下部のリッチメニューは、上部の **3 つのタブ** で切り替えます。タブをタップするとボタンの一覧が切り替わります（トークにメッセージは送られません）。

### 写真報告

| メニュー | 機能 |
|---|---|
| 報告書作成 | 工事情報を入力して、新しい写真報告書を作成する（工事情報フォーム） |
| 写真選択 | 現場の写真を選んで送る |
| あずさアドバイス | アドバイスをもらう報告書を選ぶ |
| 写真報告書リスト | 写真報告書の一覧を開く（業務フローの報告書は含まれません） |
| 工事履歴 | マイページ（Web）で自分の工事・報告履歴を確認する |

### 業務報告

| メニュー | 機能 |
|---|---|
| 業務開始 | 業務フローを選んで入力を始める |
| 業務報告書リスト | 業務フローの報告書の一覧を開く |

### 使い方

| メニュー | 機能 |
|---|---|
| 使い方ガイド | このユーザーマニュアルを開く |
| 操作動画 | 操作説明の動画を開く |

- トークで「報告書リスト」と送ると、写真報告書と業務フローの報告書をまとめて表示します。
- **言語**: LINE の言語設定が日本語以外の方には、英語のリッチメニューが表示されます。LINE の言語を変えた場合は、次にトークでメッセージを送ったとき（「写真報告書リスト」など、押すとメッセージが送られるボタンを含む）に切り替わります。タブの切り替えや、ページを開くボタンだけでは切り替わりません。メッセージは日本語・英語のどちらでも認識されます。
- 業務フローを利用していない会社では、業務報告タブのボタンを押すと、利用できない旨をお知らせします。
